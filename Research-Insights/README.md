# Research Insights

## Purpose

Biến dữ liệu tham khảo thành evidence và knowledge có provenance.

## Responsibilities

Channel data, source video, transcripts, analysis, evaluation và learning records.

## Inputs

Nguồn công khai, local media được bàn giao và dated platform snapshots.

## Outputs

Digest, metrics, analysis và reusable patterns; không viết nội dung publish.

## Source of truth

Run bundle có source/provenance sidecar và evidence pointer.

## Folder structure

`Library/channels`, `Library/videos`, `Library/transcripts`, `Library/analysis`,
`Library/evaluation`, `Library/knowledge`.

## Workflow

Collect -> verify provenance -> analyze -> evaluate -> learn -> handoff.

## Approval requirements

Cần approval trước paid scrape/API hoặc mở rộng thu thập ngoài brief.

## Naming conventions

Run ID và ngày ISO; không ghi đè run cũ.

## Archive policy

Giữ raw evidence; supersede knowledge entry thay vì xóa.

## Related departments

Brand-Strategy, Marketing-Growth, Data-Analytics, Technology-Automation.
