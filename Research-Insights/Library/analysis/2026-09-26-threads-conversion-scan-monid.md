## Conversion interpretation

The four P1 posts should not receive a direct package pitch. The strongest
sequence is:

1. Answer the stated question with concrete local value.
2. Ask one qualifying question about date, Hanoi inclusion, solo/group status,
   or preferred pace.
3. Mention TravelFrame only when a private local route, confidence support, or
   visual memory service genuinely solves the stated problem.
4. Move to DM only after the author shows interest.

Suggested qualification fields: travel dates, Hanoi nights, solo/group status,
preferred mood, and whether photos/video matter to the trip.

## Limitations

- TikHub search returned public post data, not a complete or exhaustive Threads index.
- Several exact multi-word searches returned no results despite broad searches succeeding.
- The post-comment endpoint returned HTTP 400 for all six shortlisted posts; failed calls were not billed.
- Comment context was therefore not available, so no claim is made about whether another reply already solved the user's need.
- Weather and other dated travel facts must be checked again immediately before any public response.
- Public engagement or outreach requires separate approval and a final context check in Threads.
