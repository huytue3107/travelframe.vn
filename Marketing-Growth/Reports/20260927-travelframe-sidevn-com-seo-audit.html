Small fixes, in order

Replace demo marquee photos medium

Eight images inside the homepage photo marquee track (such as tour-old-quarter.jpg and news-1.jpg) are fallback demo files carrying generic alt="Hanoi" labels instead of genuine guest photos.

Fix: In the Drupal admin panel under General Settings (/travelframe-admin/settings), upload 6 to 8 authentic guest photos into the Marquee images field. The custom uploads automatically override the demo fallback images and their generic labels.

Redirect discontinued tour URLs medium

Google Search Console reported two 404 Not Found errors for deleted tour URLs: /tour/bun-cha-grill-tour and /tour/tour-bun-cha-do-nuong.

Fix: Add a 301 permanent redirect sending both legacy URLs to the active culinary tour page https://travelframe.sidevn.com/tour/taste-hanoi-culinary-delights-street-vibes.

Configure www subdomain redirect low

Visiting https://www.travelframe.sidevn.com returns an HTTP 400 Bad Request error rather than redirecting to the primary domain.

Fix: Request hosting support or update the LiteSpeed web server configuration to redirect all www.travelframe.sidevn.com traffic permanently with a 301 header to https://travelframe.sidevn.com.

Correct navigation menu label low

The primary desktop and mobile navigation header labels the article section as New rather than News.

Fix: In Drupal admin under Menus (/admin/structure/menu/manage/main), edit the menu link title from "New" to "News" (or "Stories").

Redirect /blog to /news low

Visiting https://travelframe.sidevn.com/blog returns an HTTP 404 error, while all 15 published articles are organized under the /news/* path.

Fix: Add an internal path redirect so requests for /blog seamlessly take visitors to /news.

Clean up tour schema entity encoding low

The JSON-LD structured data on tour pages contains double-escaped ampersands: &amp;amp; in tour titles (such as French Colonial &amp;amp; Historical Footsteps).

Fix: Adjust the tour template filter so structured data outputs raw characters (&) rather than double-encoded HTML entities.
