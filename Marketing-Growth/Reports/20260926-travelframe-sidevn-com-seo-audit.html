If you only do one thing

Submit your verified XML sitemap to Google Search Console this week.

A sitemap is a list of every important page on your website that helps search engine crawlers find and read your content. Because your domain is new with zero incoming links, submitting your sitemap is the fastest way to request Google to crawl and index your 33 pages.

  1. Log in to Google Search Console with your company Google account and add https://travelframe.sidevn.com as a URL prefix property.

Small fixes, in order

Replace generic image alt text medium

Alt text is the written description attached to an image for screen readers and search engines. Every image on the homepage currently uses the single identical word alt="Hanoi", such as <img src=".../tour-old-quarter.jpg" alt="Hanoi">.

Fix: In Drupal media library, write a specific, plain description for each photo (for example, "Guide and travelers walking past yellow French colonial shutters in Hanoi Old Quarter").

Clarify the main homepage headline medium

The primary H1 tag is the main heading that search engines treat as the primary topic of the page. The homepage H1 is currently <h1>Experience Hanoi. Take home the memories.</h1>, which describes the feeling but omits what the business actually provides.

Fix: Update the main heading or add a clear subtitle containing your core service and city, such as "Private Hanoi Walking Tours with Candid Photography Keepsakes".

Fix navigation menu label typo low

In the primary website menu, the link pointing to /news is labeled New instead of News or Stories.

Fix: In Drupal Administration under Structure -> Menus -> Main navigation, change the title from "New" to "Stories" or "Travel Guide".

Clean HTML entities in tour structured data low

Structured data is hidden code that tells search engines whether a page is an article, a tour, or a business. On tour pages, the title contains an escaped ampersand: "name": "The Spiritual &amp; West Lake Breeze".

Fix: In the template outputting JSON-LD, ensure ampersands are output as plain & characters rather than HTML entities.

Add 301 redirect for the /blog address low

A 301 redirect is a permanent rule that forwards visitors from an old or alternative address to the correct page. Visiting https://travelframe.sidevn.com/blog returns a 404 page not found error, even though your travel articles exist at /news.

Fix: Set up a redirect rule in Drupal forwarding /blog directly to /news so visitors who type the word blog do not see an error.

Handle www subdomain traffic low

Requesting https://www.travelframe.sidevn.com returns an HTTP 400 Bad Request error rather than redirecting to the main address.

Fix: Ask your server host to route any request with a www prefix directly to https://travelframe.sidevn.com.
