Where the site stands

The website has a clean technical base: 55 public pages load in under 250 milliseconds, mobile viewport tags are correctly set across all screens, and sitemap.xml accurately reflects the live site structure. Over 50 pages already include structured data (schema markup, which is hidden background code that explicitly explains page details like articles and services to search engines).

The primary vulnerability is domain identity. The site currently serves on the temporary subdomain travelframe.sidevn.com, and every page uses a self-referential canonical tag (a hidden tag telling search engines that this subdomain address is the single official version). Meanwhile, the official domain travelframe.vn has no DNS records configured. The longer the temporary address stays live with canonical tags pointing to itself, the more Google treats the subdomain as the real home, requiring an avoidable migration cleanup later.

Small fixes, in order

Restore field guide PDF download high

The link https://travelframe.sidevn.com/guides/TravelFrame-Hanoi-Photographer-Tour-Guide.pdf returns an HTTP 404 Not Found error. Google Analytics recorded five different visitors attempting to download this file and hitting a dead end.

Fix: Upload the compiled field guide PDF to the web server path public/guides/TravelFrame-Hanoi-Photographer-Tour-Guide.pdf so visitors and social leads receive the promised document immediately.

Redirect broken /tour to /tours high

Visitors who omit the trailing "s" and type https://travelframe.sidevn.com/tour receive an HTTP 404 page. Three distinct visitors encountered this error in the past week.

Fix: Add a 301 redirect rule in your web server configuration mapping /tour permanently to https://travelframe.sidevn.com/tours.

Redirect missing digital tour page medium

The URL https://travelframe.sidevn.com/digital-tour returns an HTTP 404 error, even though analytics recorded 29 pageviews from visitors seeking the interactive map.

Fix: Either re-publish the digital tour route or add a 301 redirect sending traffic from /digital-tour to the tours catalog at /tours.

Remove duplicate brand name in article titles medium

Five blog articles contain a duplicated brand suffix in their title tag, for example: Bun Cha Chan: A Local Culinary Guide | TravelFrame | TravelFrame Vietnam on /news/bun-cha-chan-local-culinary-guide. This wastes title character space.

Fix: Edit the blog template in Drupal settings so the brand suffix appends only once as | TravelFrame Vietnam.

Trim titles exceeding 65 characters medium

41 of 55 pages have title tags longer than 65 characters. For example, 15 Best Photo Spots in Hanoi: Local Photographer Guide (2026) | TravelFrame Vietnam is 83 characters long, causing Google to truncate the end with an ellipsis on search result pages.

Fix: Shorten article titles to 50-60 characters so the core topic and brand remain fully visible in mobile and desktop search results.

Add alt text to 6 blog images low

Six image elements across five articles (including Bat Trang pottery and Cam Phu Cau incense guides) lack alt text (a short written description helping search engines and visually impaired visitors understand the image content).

Fix: In Drupal admin, open each of the five articles and enter a concise 5-8 word description in the Image Alt field, such as "Artisan handcrafting ceramics at Bat Trang pottery village".

Expand tour schema with pricing and reviews low

The seven private tour pages currently use generic Service schema markup. They omit structured data properties for price currency, starting rate, duration, and customer ratings.

Fix: Upgrade the structured data template on tour pages to include TouristTrip or Product schema with offers (price in USD/VND) and aggregate review scores to qualify for rich snippets in Google search results.
