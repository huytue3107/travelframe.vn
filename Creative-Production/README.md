# Creative Production

## Purpose

Sản xuất hình ảnh, video, carousel, guide và deliverable.

## Responsibilities

Raw assets, production source, edit, render, QA, delivery và usage evidence.

## Inputs

Approved brief, source media, brand direction và asset plan.

## Outputs

Reviewed render và final deliverable; không tự publish.

## Source of truth

Project manifest, source assets và final checksum.

## Folder structure

`Assets/Raw/`, `Assets/Stock/`, `Assets/AI-Generated/`, `Projects/`, `Review/`, `Deliverables/`, `Runbooks/`.
- `Runbooks/Visual-Asset-Pipeline-Guide.md`: Hướng dẫn toàn diện tìm ảnh Pexels API & render Nano Banana AI.

## Workflow

Ingest -> plan -> source/generate (Pexels / Nano Banana) -> edit -> render -> QA -> approve -> handoff.

## Approval requirements

Cần approval khi dùng ảnh khách, paid generation, final delivery hoặc publish handoff.

## Naming conventions

Giữ filename nguồn; project folder dùng Title-Case-Kebab.

## Archive policy

Giữ source và final; cache/intermediate chỉ dọn sau manifest review.

## Related departments

Marketing-Growth, Brand-Strategy, Operations, Technology-Automation.
