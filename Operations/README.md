# Operations

## Purpose

Giữ Company OS ổn định, có thể kiểm tra và quay lại.

## Responsibilities

SOP, workflow, inventory, migration, capacity, maintenance và change records.

## Inputs

Process requirements, incidents, migration manifests và department feedback.

## Outputs

Runbook, checklist, validation report và operating cadence.

## Source of truth

Approved SOP và migration record đã validation.

## Folder structure

`Migrations/`, `Change-Management/`, `Runbooks/`, `Checklists/`.

## Workflow

Baseline -> plan -> execute batch -> validate -> record -> close.

## Approval requirements

Cần approval cho destructive cleanup, permission changes và cross-department redesign.

## Naming conventions

Migration dùng `MIG-YYYYMMDD-SCOPE`.

## Archive policy

Migration history và rollback record không được xóa.

## Related departments

Tất cả phòng ban.
